# Swalekhani - Official Letterpad Generator

Swalekhani is India's most advanced and beautiful official letterpad generator, designed specifically for Government Ministries, Member of Parliaments, MLAs, Industry Professionals, and Personal use. Built with Next.js, it supports deep customization and is powered by AI for smart letter generation.

## Features
- **Smart AI Assistant**: Automatically draft official, DO, circular, or personal letters based on small prompts.
- **Dynamic Layouts**: Easily switch between Government templates, Ministry headers, District templates, and clean Personal templates.
- **Inline Editing**: WYSIWYG text formatting right on the A4 page layout.
- **Export & Print**: Pixel-perfect A4 printing or PDF exporting built right in.

## Deployment on Vercel
Deploying this Next.js app to Vercel is extremely easy:
1. Push this repository to GitHub.
2. Log into [Vercel](https://vercel.com).
3. Click **Add New Project** and import this "swalekhani" repository.
4. Vercel will automatically detect it as a Next.js project. No extra build settings are required.
5. Click **Deploy**!

## Usage
Simply start editing by clicking on any text field on the letter. Or, open the ? AI Assistant in the bottom right to ask it to generate a 1-3 page letter for you!
